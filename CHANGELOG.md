# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-01-23

### Added
- Initial release of React Source Spotlight
- CLI tool for generating source code maps
- `SpotlightProvider` context component
- `Spotlight` wrapper component with hover detection
- `DevModeToggle` floating button
- `CodeModal` with syntax highlighting
- `useSourceSpotlight` hook for programmatic control
- Clean Code Badge for components under 100 lines
- One-click copy to clipboard
- GitHub deep links
- Keyboard shortcut (Ctrl+Shift+D) support
- Responsive design for mobile and desktop
- Dark theme with Night Owl syntax highlighting
- Configuration file support
- TypeScript support
- Comprehensive documentation
